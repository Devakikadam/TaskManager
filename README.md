# Task Manager

## 📌 Project Description
This is a simple Task Manager application built using Java.
It allows users to manage their daily tasks easily.

## 🚀 Features
- Add Task
- View Tasks
- Delete Task

## 💻 Technology Used
- Java

## ▶️ How to Run
1. Compile the program:
   javac TaskManager.java

2. Run the program:
   java TaskManager

## 📷 Sample Menu
1. Add Task  
2. View Tasks  
3. Delete Task  
4. Exit  

## 📚 Conclusion
This project helps users to organize and manage tasks efficiently.
